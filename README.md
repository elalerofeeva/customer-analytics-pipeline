# customer-analytics-pipeline


Учебный проект для демонстрации базового инструментария AI/ML Engineer.

## Что включает проект
- Git и GitHub workflow
- Python для обработки данных
- SQL для работы с базой данных
- построение клиентской витрины и признаков

## Структура
- `data/` — исходные и результирующие данные
- `notebooks/` — Jupyter Notebook для лекции
- `scripts/` — Python-скрипты
- `sql/` — SQL-запросы
- `shop.db` — SQLite-база данных

## Назначение
Проект используется для демонстрации того, как данные проходят путь от источника хранения до обработки, аналитики и подготовки признаков.

## Базовый сценарий работы
1. Подготовить CSV-файлы в папке `data`
2. Запустить `scripts/init_db.py`
3. Проверить SQL-запросы из `sql/demo_queries.sql`
4. Выполнить `scripts/sql_demo.py`
5. Построить признаки через `scripts/build_features.py`
